Odwiedź Żywe Portfolio Bartka 🌍
           
       

Dlaczego APEX, a nie zwykły kurs programowania? 🎯

       

            Większość zajęć IT dla dzieci to bezstresowe świetlice – nauka kończy się na przesuwaniu kolorowych klocków, z których po powrocie do domu nic nie wynika. W Akademii APEX wywracamy ten model do góry nogami.        

       

            🚀 Już po pierwszych zajęciach Twoje dziecko uruchomi własną, żywą stronę internetową w chmurze GitHub i wróci do domu z unikalnym linkiem, którym pochwali się rówieśnikom.        

       

            To portfolio nie jest statyczną makietą – to cyfrowy fundament, który uczeń będzie samodzielnie rozwijał przez cały rok, zarządzając pracą profesjonalną metodologią SCRUM i kontrolą wersji GIT. Zobacz, jak wygląda roczna ścieżka ewolucji od użytkownika do młodego Architekta Oprogramowania.        

   
   
       

Roczny Program Deweloperski (Syllabus)

       

Cztery kwartały inżynierii, logiki i komercjalizacji projektów.

   
   
                       
           
               

🍁 Kwartał 1: Moje Pierwsze Portfolio & SCRUM

                Web + Git Starter            
           

Cel główny: Natychmiastowy start w sieci i wdrożenie dyscypliny projektowej.

           
                   
  • • Dzień 1 (Wdrożenie): Założenie konta GitHub i uruchomienie serwera produkcji przez GitHub Pages.
    •                
  • • Zarządzanie Tablicą Kanban: Planowanie tygodniowych sprintów i realizacja zadań biograficznych w kodzie.
    •                
  • • Podstawy HTML5 & CSS: Budowanie czystej struktury tekstu (nagłówki, akapity) i wstrzykiwanie stylów wizualnych.
    •            
       
               
           
               

❄️ Kwartał 2: Cyfrowy Storytelling & Interakcja

                Multimedia + Backend            
           

Cel główny: Wzbogacenie portfolio o autorskie materiały wideo oraz uruchomienie interakcji z użytkownikiem.

           
                   
  • • Inżynierski Montaż Wideo: Praca w CapCut – cięcie audio, zaawansowane napisy i animacje okienkowe.
    •                
  • • Projekt Domowy: Nagranie własnego tutorialu/prezentacji i osadzenie pliku wideo na swojej stronie.
    •                
  • • Uzbrojenie Formularzy: Integracja strony z webhookami (Formspree) do zbierania opinii od pierwszych użytkowników.
    •            
       
               
           
               

🌸 Kwartał 3: Zaawansowana Algorytmika & Gry

                Scratch + Matematyka            
           

Cel główny: Wejście w czystą logikę logiczno-matematyczną bez pisania nudnego kodu tekstowego.

           
                   
  • • Czyste Struktury Logiczne: Zmienne, optymalizacja pętli i unikanie "makaronu w kodzie" w Scratchu.
    •                
  • • Math przez Kod (Driven by Need): Tworzenie asystentów matematycznych (dzielenie pisemne, ułamki, współrzędne).
    •                
  • • Architektura Zdarzeniowa: Komunikaty Broadcast jako mechanizm wielowątkowości i klonowania obiektów.
    •            
       
               
           
               

☀️ Kwartał 4: Zaawansowany DevOps & Finał APEX

                Branching + Git Workflow            
           

Cel główny: Przejście na profesjonalny Git Workflow, pełna integracja systemów i obrona projektu.

           
                   
  • • Zrozumienie Grafu DAG: Izolacja zmian na gałęziach testowych (branching), procedury Pull Request i Merge.
    •                
  • • Wielka Integracja: Osadzenie wypracowanych silników gier ze Scratcha bezpośrednio w portfolio HTML przez tagi iframe.
    •                
  • • Egzamin APEX (Showcase): Publiczna prezentacja swojego kodu, historii commitów i tablicy przed rodzicami.
    •
